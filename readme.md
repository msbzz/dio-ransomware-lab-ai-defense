# DIO — Ransomware Lab AI Defense

## Sobre o projeto

Projeto educacional desenvolvido como parte de um desafio da **Digital Innovation One (DIO)**, com o objetivo de simular um ataque de ransomware em ambiente controlado e estudar técnicas de detecção, contenção e recuperação utilizando Inteligência Artificial.

O laboratório utiliza **Python, VMware Workstation, Windows 7 e Hermes AI Agent**.

## Objetivos

- Desenvolver um simulador de ransomware em Python.
- Simular a criptografia e descriptografia de arquivos fictícios.
- Investigar atividades suspeitas utilizando o Hermes AI.
- Aplicar técnicas de contenção e recuperação.
- Documentar os testes e as medidas de segurança adotadas.

## Ambiente de laboratório

- **Máquina hospedeira:** Windows 11 com Hermes AI.
- **Máquina virtual:** Windows 7.
- **Virtualização:** VMware Workstation.
- **Rede:** Host-Only, isolada da rede externa.
- **Linguagem:** Python.

## Status do projeto

🚧 **Em desenvolvimento**

Atualmente, o ambiente virtual está configurado e os primeiros testes de conectividade entre o Hermes e o Windows 7 foram realizados.

As próximas etapas incluem o desenvolvimento do simulador, a investigação com IA e a documentação dos resultados.

## Aviso

Este projeto possui finalidade exclusivamente educacional. Todos os experimentos serão realizados em ambiente controlado, utilizando arquivos fictícios, sem intenção de causar danos a sistemas reais.
